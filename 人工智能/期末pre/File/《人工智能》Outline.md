# 二、概念介绍（略详）
## 2.1 具身智能概念界定 （九宫格）
具身智能（Embodied Intelligence）是人工智能与机器人学交叉的前沿领域，强调智能体通过身体与环境的动态交互实现自主学习和进化，其核心在于将感知、行动与认知深度融合‌。
具身智能(Embodied AI)是指 AI 系统不仅具备感知和思考能力,还能通过物理实体(如机器人)与真实环境进行交互的技术。与传统 AI 仅在虚拟空间处理信息不同,具身智能需要: 
1.  感知能力:通过传感器获取环境信息(视觉、触觉、听觉等) 
2.  理解能力:基于大模型理解任务目标和场景语义 
3.  决策能力:规划执行路径,生成动作序列 
4.  执行能力:通过机械臂、移动底盘等执行器完成物理操作
5.  学习能力:从交互经验中持续优化性能  
![[Pasted image 20251214144748.png]]

2022 年,Google DeepMind 提出的 RT-1(Robotics Transformer 1)模型开启了新纪元。RT-1 首次将 Transformer 架构应用于机器人控制,实现了从视觉输入到动作输出的端到端学习。但真正的突破来自 2023 年的 RT-2 模型——它将互联网规模的视觉-语言预训练知识迁移到机器人控制中,首次提出了 VLA(Vision-Language-Action)模型的概念。

# 三、发展历程（略）

## 3.1 早期萌芽阶段（1950-1990）
1950年，艾伦·图灵在其论文《Computing Machinery and Intelligence》中首次提出具身智能的概念，强调智能与身体和环境的紧密联系。
1956年达特茅斯会议后，符号主义主导了AI早期发展，试图用逻辑规则、符号、知识工程来模拟人类思维。连接主义则强调通过神经网络模拟人类大脑的学习和计算能力，但早期的连接主义模型是简单的、浅层的网络。

## 3.2 行为主义与早期机器人学时期 (20世纪80-90年代)
1980年代，罗德尼·布鲁克斯（Rodney Brooks）提出行为主义AI，主张通过身体与环境的交互来产生智能。
1986年，布鲁克斯从控制论角度出发，提出行为式机器人概念，认为智能是具身化和情境化的。
1991年，布鲁克斯在其论文《无表征的智能》中首次提出，智能行为可以通过自主机器与环境的简单物理交互直接产生，而无需复杂算法或内部表征。

## 3.3 发展停滞与算力储备期 (20世纪90年代-21世纪00年代)
传统AI的复兴：基于统计的机器学习和随后兴起的深度学习在语音、图像等特定领域取得巨大成功，但这些研究大多脱离了物理身体，集中在虚拟世界的感知和决策。
机器人技术的缓慢积累：同时期，机器人学在机构设计、传感器、控制系统等硬件和基础算法上持续进步，为后来的融合打下了基础。

## 3.4 技术积累阶段（1990-2022）
1. 理论与算法基础奠定：AI三大学派走向综合性研究，行为主义发展，如布鲁克斯提出智能行为可从简单物理交互产生。深度学习、强化学习、形态计算等理论及算法模型取得突破，如深度强化学习、模仿学习等。

2. 机器人技术的发展：这一阶段关注仿生机器人研发和智能化水平提升，如Kismet、AIBO、Roomba等机器人出现。无人驾驶技术、无人机应用、服务机器人等领域也取得显著进展。

## 3.5 技术突破阶段（2022年至今）
1. 算法层：

	大模型推动具身智能发展：以ChatGPT为代表的大模型为机器人智能感知、自主决策、拟人化交互带来巨大潜力。例如，VoxPoser模型、PaLM-E具身多模态语言模型、NaviLLM等新进展，大幅提高了机器人语言交互、环境感知和任务决策等能力。
	多模态融合与自主学习：具身智能技术从模块化AI算法集成转向大模型驱动的统一技术框架，实现了通用性和泛化性的突破。其技术体系分为“感知-决策-行动-反馈”四个模块，形成闭环，实现环境重构映射、自主决策和自适应行动，并从经验反馈中学习进化。

### 4.1.2 小鹏IRON——VLT+VLA+VLM架构协同机制：驱动控制的核心支撑

**1）** **模块功能定位**

**三者形成递进式协同：**
VLT作为**多模态特征对齐中枢**，采用统一Transformer架构，将图像分块与文本Token混合输入，端到端处理全身摄像头、触觉传感器等多源数据，生成结构化环境与姿态特征，解决传统CNN局部感受野局限，实现全局环境建模；
VLM作为**语义理解与知识推理中枢**，基于预训练-微调范式，解析用户语音/文本指令（如“拾取杯子”），识别物体属性与场景需求，完成视觉与语言信息的跨模态对齐；
VLA作为**决策与控制中枢**，采用分层设计，高层基于VLM输出规划任务流程（如“抓取-移动-放置”），**低层通过扩散模型解码连续动作，直接生成关节控制指令，其创新的无语言转译设计，跳过传统文本中间层，实现视觉信号到动作指令的端到端生成，响应延迟大幅降低。**

**2）数据流协同**

### 4.2.1 LLMs（大语言模型）及MLLMs（多模态大语言模型）

[Deepsleep here]
大语言模型是近年来人工智能领域最具革命性的技术突破之一，指在超大规模文本数据集上进行预训练的、参数数量巨大（通常达数十亿甚至数万亿级别）的深度学习模型。这类模型通过自监督学习，掌握了语言的统计规律与语义关联，能够处理各种语言任务，展现出强大的理解、生成与推理能力。
![[Pasted image 20251215183934.png]]

1. 规模巨大
   模型参数量可达千亿级别（如GPT-3有1750亿参数），训练数据覆盖互联网文本、书籍、代码、对话等多元来源，使其具备丰富的世界知识与语言表达能力。

2. 泛化能力强
   无需针对特定任务进行微调，仅通过提示工程（Prompt Engineering）或少量示例（Few-shot Learning）即可完成翻译、问答、代码生成、逻辑推理等多种任务。

3. 多模态扩展
   随着技术发展，LLM逐渐与视觉、语音等模态结合，形成多模态大模型（如GPT-4V、LLaVA），能够处理图像、文本、语音等多种输入，实现跨模态理解与交互。

4. 涌现能力
   当模型规模达到一定程度后，会出现一些在较小模型中未见的能力，如复杂推理、指令跟随、思维链（Chain of Thought）等，这些能力使其在交互与规划任务中表现突出。

### 4.2.2 WMs（世界模型）

世界模型（_World Models_）是人工智能领域一个至关重要的概念，它指的是一个能够对环境或世界的状态进行表征，并预测状态之间转移的模型 。这个模型的核心目标是让AI系统能够像人类一样，在内部构建一个对外部物理环境的模拟和理解 。核心思想是，通过训练一个生成式模型来模拟环境的动态，从而为智能体提供一个可以进行“想象”的内部世界。
**核心要素：**

1. 观测（_Observation_）

	从环境中接收到的原始感官数据，并通过降噪等方式处理提取信息。
2. 状态（_State_）

	状态是对世界在某一时刻的完整描述。世界模型的目标之一就是维护一个对世界状态的准确估计。
3. 行动（_Action_）

	行动指智能体能够做到的影响外部环境的功能，世界模型需要能够预测不同行动可能带来的后果。
4. 潜在变量（_Latent Variable_）

	潜在变量代表了那些无法被观测到的、但对世界演化有重要影响的信息。通过从某个分布中采样潜在变量，世界模型可以生成一组合理的未来预测，从而处理现实世界中的不确定性 。
智能体通过观测来更新其对世界状态的估计，然后通过模拟不同行动在不同潜在变量影响下的结果，来进行规划和决策。

**模型架构**
![[Pasted image 20251215185112.jpg]]
 - 视觉模型(_Vision Model, V_）：感知与表征
将高维的、充满噪声的原始感官数据，转化为低维的、结构化的潜在表示，为整个系统的后续运作奠定了基础。
 - 记忆模型（_Memory Model, M_）：学习与预测.
 学习环境在时间维度上的动态变化规律，并基于当前的状态和行动来预测未来的状态 。
 -  控制器（_Controller, C_）：决策与规划
基于已知的现实状态与预测的未来状态，来做出最优的决策和规划 。
